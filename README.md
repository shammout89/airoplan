# AeroPlan 0.16.0

نظام تخطيط صيانة الطائرات بواجهة عربية، مع برامج ومهام واستحقاقات ووحدات ومكونات وحزم وموارد ووثائق ومخزون ومتطلبات فنية واعتمادية ونسخ واستعادة.

ابدأ من [دليل الإصدار والتشغيل](docs/CUSTOMER_SETUP_0_16_0_AR.md). تتوفر [مسارات العمل](docs/WORKFLOWS_0_13_AR.md)، و[الأمن والتعافي](docs/SECURITY_0_13_AR.md)، و[تقرير الاختبارات](docs/TEST_REPORT_0_16_0_AR.md)، و[قائمة التنفيذ](IMPLEMENTATION_CHECKLIST.md).

الحزمة مصدر تطبيق قابل للبناء. تنشئ التثبيتات الجديدة حساب المالك تفاعليًا؛ لا توجد بيانات شركة أو كلمات مرور افتراضية. يحافظ تحديث التثبيت القائم على بياناته وإعداداته، كما يوضح دليل الإصدار.

التقنيات: React وTypeScript وVinext، مع بوابة Node وSQLite ومخزن مرفقات خاص في التثبيت المحلي. يتوفر مسار استضافة Cloudflare منفصل، وتُراجع ضوابط هوية ذلك المسار عند اختياره.

```bash
npm ci
npx tsc --noEmit
npm run build:docker
npm run test:docker
```

تعتمد الاختبارات على بيانات اصطناعية وقواعد مؤقتة؛ يوضح التقرير نطاق التحقق الفعلي وما يتطلب جهاز الشركة وبياناتها. لا تحل نتائجها محل قبول المختص أو اعتماد الجهة المنظمة.

إعداد Windows وDocker: [DOCKER_AR.md](DOCKER_AR.md). المراجع السابقة تبقى محفوظة حسب أرقام إصداراتها. مرجع أدوات التطوير والاستضافة الأصلي: [DEVELOPMENT_STARTER.md](docs/DEVELOPMENT_STARTER.md).

حالة المنتج الموجه للبيع وخطوات استكماله: [PRODUCT_READINESS_AR.md](docs/PRODUCT_READINESS_AR.md).
