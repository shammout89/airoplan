# مزامنة قوائم الطائرات — AeroPlan 0.14.2

## التغيير

كانت الإعدادات ونموذج الطائرة يقرآن واجهة الخادم نفسها، لكن كل مكوّن يحتفظ بنسخة محلية، دون إشعار تحديث بينهما. أصبحت الشاشة والنموذج داخل الصفحة يقرآن مخزنًا مشتركًا واحدًا، مربوطًا بالمستخدم وجيل الاستعادة الحالي. يؤدي نجاح الحفظ في الإعدادات إلى إعادة القراءة وتحديث جميع المستهلكين.

تُرسل إشارة تغيير بين التبويبات والنوافذ من المصدر نفسه بواسطة BroadcastChannel، مع بديل storage عند غيابه. لا تحمل الإشارة أسماء القوائم أو بيانات الحساب؛ تؤدي إلى قراءة مصرح بها من الخادم. عند عودة التبويب للظهور أو التركيز يُعاد التحديث. تُفحص البيانات دوريًا كل 15 ثانية طالما التبويب ظاهر والقائمة أو النموذج مستخدم، لتشمل تعديلات مستخدم آخر أو متصفح آخر. تتوقف طلبات المزامنة الدورية عند عدم وجود مستهلك، وتزال المستمعات والمؤقتات عند مغادرة الصفحة.

تُدمج طلبات القراءة المتزامنة، وتُلغى الطلبات السابقة عند تحديث إلزامي، ويمنع رقم الطلب وصول رد قديم فوق حالة أحدث. عند فشل القراءة يظهر خطأ ووقت آخر مزامنة، وتبقى البيانات السابقة للعرض وتُعطل الاختيارات حتى نجاح إعادة المزامنة. إذا نجح الحفظ ثم فشلت القراءة اللاحقة تظهر رسالة تفصل الحفظ الناجح عن فشل تحديث العرض.

## الترابط والمسميات

المصادر الخمسة هي: الشركة المصنّعة، العائلة التابعة لها، الطراز الدقيق التابع للعائلة، بلد التسجيل، والجهة الرقابية التابعة للبلد. تظهر قيم كل تبويب في حقلها المقابل، وتُصفّى الحقول التابعة وفق الأصل المختار. وجود عائلة تحت مصنع آخر أو جهة تحت بلد آخر يفسر عدم ظهورها ضمن ذلك الاختيار؛ تظهر إرشادات بهذا المعنى.

تتحدث أسماء وإصدارات الاختيارات الجديدة غير المحفوظة داخل المسودة عند تعديل القيمة النشطة، مع الاحتفاظ بمعرفات الاختيارات والعدادات والملاحظات وإلغاء تأكيد الرصيد حتى يعاد مراجعته. تحتفظ الطائرات المحفوظة بمسمياتها التاريخية؛ يظهر المسمى الحالي بجانب المسمى المحفوظ عند اختلافهما. لا تُعاد كتابة سجلات الطائرات أو عداداتها تلقائيًا.

عند تعطيل اختيار جديد أو تغير ارتباطه يظهر تنبيه وخيار غير متاح، ويُطلب اختيار قيمة نشطة صحيحة قبل التفعيل. تبقى اختيارات السجلات السابقة محفوظة وفق القواعد السابقة، ويظل الخادم هو المرجع النهائي للصلاحيات والروابط وصحة التفعيل.

يتضمن التحديث إصلاح 0.14.1 للسهم داخل الصندوق. لا حاجة إلى تطبيق حزمة السهم منفصلة فوق هذا التحديث.

## تطبيق التحديث على جهازك

آخر مخرجات /healthz التي قدمها المستخدم أثبتت تشغيل 0.14.0 وبصمة 787d193f7e2cfb239071229b03a826349c83ce86d3f39663bcc3b752530cca02. الحزمة AeroPlan-Sync-Update-0.14.2.zip تراكمية من 0.14.0 وتصلح لتحديث 0.14.0 أو 0.14.1. تشمل المصدر والاختبارات والتوثيق، وتحفظ compose.yaml و.env وملفات الخدمات المُولّدة والبيانات والأسرار. لا تغير الترحيلات أو الحسابات أو المصادقة أو سياسات الصلاحيات.

نزّل الحزمة إلى Downloads وشغّل Docker Desktop. نفّذ كل سطر منفردًا واضغط Enter، دون استخدام كتلة PowerShell متعددة الأسطر أو استدعاء سكربت غير موقّع.

أولًا، فك الحزمة إلى مجلد النظام الحالي:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\AeroPlan-Sync-Update-0.14.2.zip" -DestinationPath "$env:USERPROFILE\Downloads\AeroPlan-Docker" -Force -Verbose
Get-Content "$env:USERPROFILE\Downloads\AeroPlan-Docker\release.json"
```

يجب أن يظهر version = 0.14.2 في الملف. توقف عند أي خطأ في فك الحزمة بدل البناء بمصدر سابق.

أعد البناء بالمشروع نفسه وملفات التشغيل الموجودة:

```powershell
Set-Location "$env:USERPROFILE\Downloads\AeroPlan-Docker"
$AeroFiles = @('-f', 'compose.yaml')
if (Test-Path '.\compose.production.yaml') { $AeroFiles = @('-f', 'compose.production.yaml') }
foreach ($AeroExtra in @('compose.backup.yaml', 'compose.services.yaml')) { if (Test-Path $AeroExtra) { $AeroFiles += @('-f', $AeroExtra) } }
docker compose -p aeroplan @AeroFiles up -d --build --force-recreate --wait
```

سطور تجهيز المعاملات لا تطبع نتيجة عادةً؛ يعرض سطر Docker تقدم البناء والتشغيل. انتظر اكتماله وعودة مؤشر PS. إذا فشل البناء أرسل رسالة الخطأ، ولا تعتبر استخراج الملفات دليلًا على تحديث الحاوية.

تحقق من الخادم العامل:

```powershell
Invoke-RestMethod 'http://localhost:8080/healthz' | Format-List status, version, buildFingerprint
```

يجب ظهور status = ok وversion = 0.14.2. البصمة الصحيحة موثقة في تقرير التحقق. قد يبقى وسم صورة Docker قديمًا لأن ملف Compose محفوظ؛ يحدد /healthz الإصدار الفعلي. حافظ على مشروع aeroplan ووحدة البيانات الموجودة، واستعمل حساب المدير الحالي دون إعادة init أو حذف وحدات التخزين.

## القبول المطلوب في المتصفح

بعد التأكد من تشغيل 0.14.2، اضغط Ctrl+F5. افتح الإعدادات في تبويب ونموذج إضافة طائرة في تبويب آخر. أضف تعريفًا صحيحًا من مصدر شركتك، ثم عد إلى النموذج وابحث عنه. كرر ذلك لكل قائمة، مع اختيار المصنع قبل العائلة والعائلة قبل الطراز، والبلد قبل الجهة.

اختبر إعادة التسمية في مسودة غير محفوظة، ثم التعطيل وإعادة التفعيل. تأكد من عدم تغير أسماء طائرات محفوظة أو عداداتها أو ملاحظاتها. جرّب جلسة أخرى ظاهرة وانتظر دورة التحديث الدوري، ثم جرب انقطاع الشبكة وإعادة المزامنة. تحقق أيضًا من السهم داخل الصندوق والاختيار بالماوس ولوحة المفاتيح وعرض ضيق.

## التحقق وحدوده

نجح TypeScript وبناء الإنتاج وجميع مجموعات الانحدار الـ33، منها 103 فحوص جديدة للمزامنة تستدعي API الفعلي على SQLite وتشغّل طبقة العميل، مع محاكاة الإشعارات والتركيز والظهور والمؤقتات. تضمنت تعديل القوائم الخمس ثم حفظ طائرة بالاختيارات الحديثة، وحفظ المسميات التاريخية، والتعطيل وتغيير الارتباط، والرد القديم، وفشل الشبكة، والحفظ الناجح مع فشل القراءة التالية، والصلاحيات وتنظيف الاشتراكات. نجحت كذلك 99 فحص قوائم و56 فحص SSR وحالة واجهة و16 فحص تحديث وحفظ بيانات و164 HTTP إنتاج و57 مصادقة.
