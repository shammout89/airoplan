# الوثائق والمرونة — الإصدار 0.8

## الوثائق

ارفع مستندًا برمز وعنوان وإصدار، واختر ربطه بالطائرة أو المهمة أو البرنامج أو التنفيذ أو الحزمة. الملفات المدعومة PDF وDOCX وXLSX وPNG وJPEG حتى 10 MiB. يُتحقق من التوقيع الأولي للنوع وبصمة SHA-256. لا يوجد مضاد فيروسات، ويُنزّل الملف كمرفق دون عرضه كمحتوى تنفيذي.

الرفع ينشئ نسخة مستقلة في مخزن خاص. يلزم إرسال ومراجعة واعتماد مستقل قبل نشرها للمشاهد. رفع إصدار لاحق لا يحذف المنشور السابق. عنوان وروابط الإصدار المنشور لا تتغير بتعديل المسودة؛ ولا يحقق ربط غير منشور شرط المستند المطلوب للموافقة. تغيير روابط المستند يتم في المسودة. لكل إصدار مرجع واسم الرافع وتاريخ وبصمة. تنزيل الإصدار يعيد فحص البصمة.

## المخزون وربطه بالتخطيط

دليل المادة يحدد PN والمستودع والوحدة، ويبدأ رصيده بصفر. تُضاف الكميات عبر حركة استلام مراجعة ومعتمدة. طلب المادة يرتبط بمهمة أو حزمة عمل. اعتماد الطلب يحجز الكمية إذا كانت متاحة؛ إلغاؤه يعيد المتاح. الصرف يتطلب طلبًا معتمدًا وبكامل كميته، ثم مراجعة واعتماد الحركة. لا يعاد صرف الطلب، وتُرفض الكمية غير المتاحة. رقم حركة المادة ومرجعها موثقان.

هذا مخزون تخطيطي وكمي. ليس نظام مشتريات أو محاسبة أو قبول صلاحية قطع. المكونات المسلسلة والعمر تظل في وحدة المكونات القائمة؛ اعتماد كمية مادة لا يثبت صلاحيتها الفنية.

## استيراد Excel

يدعم XLSX وCSV، حتى 100 صف بيانات و5 MiB و150 عمودًا. اختر الورقة، ثم اربط الأعمدة بالحقول الأساسية أو المخصصة. المعادلات لا تُنفذ ولا تُستخدم نتائجها المخزنة: حوّلها إلى قيم أولًا. ملفات XLS القديمة تحتاج التحويل إلى XLSX. تواريخ Excel الرقمية تتحول وفق نظام تاريخ المصنف؛ النصوص يجب أن تكون YYYY-MM-DD. خزّن التسجيلات وPN التي تحتوي أصفارًا بادئة كنص في Excel.

تُعرض أخطاء كل صف على الخادم. لا تُحفظ دفعة بها أخطاء. الدفعة الصالحة تُحفظ في معاملة واحدة، مع منع تكرار تنفيذها والتحقق من تغير البيانات والحقول منذ المعاينة. الاستيراد ينشئ طائرات أو مهام يدوية أو دليل مواد؛ لا يستبدل سجلات ولا يعتمد أعمالًا أو يرحّل أرصدة.

## الحقول والنماذج

من تهيئة النظام: أضف أو عدل الحقل، ثم عاين أثر التغيير قبل الحفظ. المفتاح والنموذج ثابتان بعد الإنشاء. يُرفض تغيير النوع المستخدم وحذف خيار قائمة له قيم محفوظة. الأرشفة تحفظ القيم، وتُرفض إذا اعتمد عليها حقل فعال. الإلزامية الجديدة تسري عند الحفظ التالي للسجل؛ لا يُعدل التاريخ تلقائيًا. تحفظ تعريفات الحقول بإصدارات وسجل تغيير.

الشروط تدعم المقارنة بحقل من النموذج نفسه. الحقول المخفية لا تصبح إلزامية، وتبقى قيمتها المحفوظة. الحسابات للحقول الرقمية المخصصة فقط، باستخدام + و- و* و/ والأقواس وmin وmax وround وabs. مراجعها هي أسماء الحقول الرقمية المعرّفة، دون كود JavaScript أو خصائص أو اتصالات خارجية. يمنع الاعتماد الدائري والقسمة على صفر. الحقل المحسوب يُعاد حسابه على الخادم ولا يثق بقيمة أرسلها المتصفح. الحساب المخصص لا يغير عدادات الطائرة وحدود الصيانة الأساسية.

ترتيب النماذج يضبط مواضع حقول الطائرات والمهام. تبقى مجموعات ربط البرنامج والتحقق الأساسي ثابتة.

## التنبيهات والتقارير والموافقات

يمكن تعريف تقارير بمصدر بيانات وأعمدة وشروط وترتيب، وتصدير CSV مع حماية الخلايا النصية من تفسيرها كصيغ. التنبيه يحدد عنوانًا ومستوى وشروطًا وأدوارًا مستلمة. هذه تنبيهات داخل النظام عند فتح الشاشة أو تحديثها؛ لا توجد رسائل بريد أو SMS أو فحص مجدول في الخلفية.

الموافقات تخصص أدوار المراجع والمعتمد ويمكن أن تتطلب مستندًا منشورًا مرتبطًا قبل الإرسال. تبقى المراحل الثلاث واستقلال الأشخاص إلزامية. تثبت السياسة عند إرسال السجل؛ تعديل الإعداد لاحقًا لا يبدل سياسة سجل جارٍ. السجلات القديمة بلا سياسة مثبتة تستخدم القواعد الافتراضية المحافظة.

## التكاملات الخارجية

الربط الداخلي يعمل مع سجلات الطائرات والمهام والرحلات وحزم العمل والمخزون. يمكن إعداد اسم نظام خارجي وتنزيل تبادل JSON بإصدار مخطط AeroPlan-exchange-v1 للعمليات أو المخزون. حالة الربط صراحة «تبادل ملفات فقط». لم يُنشأ اتصال API بنظام خارجي ولم تُرسل بيانات إلى مزود خارجي. يلزم تحديد المنتج وواجهته وعينات البيانات وآلية الاعتماد والاعتمادات السرية قبل تطوير اتصال مباشر.

## النسخ والقبول

النسخة الجديدة تشمل 18 جدولًا ونسخًا مستقلة لملفات المستندات وبصماتها في المخزن الخاص. حدا البيانات 20,000 صف و8 MiB، وبحد أقصى 200 إصدار مستند. تنزيل JSON وحده لا يحتوي ثنائيات المستندات: نزّل الملفات المرتبطة بالنسخة وضعها في مجلد <snapshot.json>.files بأسماء معرفات الإصدارات للاستعادة الخارجية. أداة scripts/restore-backup.mjs تستعيد الجداول إلى D1 مستقلة، والملفات إلى R2 مستقلة، وتعيد فحص البصمات.

نسخ المخطط v6 السابقة تظل قابلة للتنزيل والفحص المنفصل، لكن استعادتها الحية إلى مخطط v8 تتطلب ترحيلًا مدروسًا؛ لا يمسح النظام الوحدات الجديدة لاستيعاب نسخة قديمة تلقائيًا. إعدادات الموافقات الحالية وإشعارات القراءة والأعضاء والتدقيق وأدلة القبول لا تُرجع إلى الماضي بالاستعادة الحية.

حالات قبول 0.8 جديدة، وكلها تحتاج توثيقًا من الشركة ومراجعة مختص. نجاح الاختبارات التقنية أو بيانات العرض الاصطناعية ليس اعتمادًا تشغيليًا.
