# AeroPlan 0.11 — نطاق التنفيذ والتحقق

لا تُعلّم أي نتيجة مكتملة قبل اختبارها. النسخة المحلية هي هدف التسليم؛ لا نشر تلقائي على الموقع المستضاف.

- [x] قبول مرتبط بمصدر الإصدار وتعريف السيناريو وبيئة التثبيت، أدلة مثبتة، مراجعة مستقلة ومحضر نهائي وإبطال المحضر عند تغير النتائج.
- [x] نسخ كامل مشفّر، جدولة، علامة وجهة خارجية، سياسة احتفاظ، مراقبة الفشل، استعادة معزولة وإبطال الجلسات.
- [x] محركات وAPU: تصنيف، عدادات مستقلة، تصحيحات مضبوطة، عمرة دون تصفير العمر، حركات وشهادات.
- [x] أعطال ومؤجلات: مراجع MEL/CDL المنشورة، احتساب متعدد الحدود والتوقيت، موافقات وتمديد وإصلاح وتتبع الاستثناءات.
- [x] تكامل REST موثق للعمليات والمخزون: تهيئة آمنة، معاينة، سجلات نقل، منع التكرار، حجز أخطاء المصدر وإعادة المحاولة.
- [x] تنبيهات وبريد وتصعيد: صندوق إرسال دائم، أدوار مستلمين، تذكير وتصعيد وإقرار، محاولات وفشل وتسليم غير مؤكد.
- [x] إنتاج: ملفات HTTPS، مراقبة الخدمة والعمليات، سجلات ومقاييس، قوائم مقسمة واختبار حمل قابل لإعادة التنفيذ.
- [x] موثوقية: مؤشرات الأعطال والإزالات والالتزام، اتجاهات وتفاصيل المصدر وتصدير وإظهار نقص البيانات.
- [x] مطابقة النسخ والاستعادة لجميع الكيانات الجديدة وفحوص العلاقات والتزامن والصلاحيات.
- [x] TypeScript وبناء Node والبناء المستضاف واختبارات HTTP وواجهة المتصفح. يُراجع محرك Docker وPowerShell وHTTPS الحقيقي على جهاز المشغّل وفق تقرير الاختبارات.
- [x] حزمة Docker تراكمية وحزمة كاملة وتعليمات Windows مستقلة الأوامر، مع حفظ مصدر الإصدار.

إعدادات الأنظمة الخارجية وSMTP واسم النطاق ووجهة الشركة الخارجية يحددها المشغّل عند التثبيت. لا تُسجل كمتصلة أو مقبولة قبل اختبار إعداداتها الفعلية. أدلة القبول التشغيلي الحقيقية لا تُملأ ببيانات اصطناعية.

تفاصيل الأدلة والحدود في TEST_REPORT_0_11.md. تعني علامة الإنجاز اكتمال التنفيذ والتحقق البرمجي الموضح؛ إعدادات الشركة وقبولها الفعلي تبقى معلقة حتى إثباتها.
