# تصحيح تواريخ تسجيل الطائرة — AeroPlan 0.14.4

هذا تصحيح محدود لتواريخ التصنيع والتسليم والانضمام للمشغّل وبدء الخدمة ومرجع الرصيد UTC. يبقي التقويم الأصلي، ويرفض السنة الأطول من أربعة أرقام والتاريخ غير الموجود والوقت غير الصحيح قبل تحويله. يطابق حدود التاريخ الموجودة أصلًا في الخادم. لا يغير القوائم أو المزامنة أو التخطيط أو الحسابات أو البيانات المحفوظة.

الحزمة AeroPlan-Date-Fix-0.14.4.zip مبنية على مصدر 0.14.3 المحفوظ، وتحافظ على إصلاحاته. يلزم تطبيقها على مجلد مصدر 0.14.3 الحالي؛ لا تُعد حزمة ترقية شاملة من إصدار أقدم. النسخة الكاملة 0.14.4 متاحة أيضًا، لكن لا تُستبدل بها ملفات تشغيلك أو بياناتك عشوائيًا.

نزّل حزمة التصحيح إلى Downloads وشغّل Docker Desktop. نفّذ كل أمر منفصلًا في نافذة PowerShell نفسها. لا يستدعي المسار سكربتًا غير موقّع.

**1. تحقق من إصدار المصدر قبل التحديث:**

```powershell
Get-Content "$env:USERPROFILE\Downloads\AeroPlan-Docker\release.json"
```

المصدر المستهدف 0.14.3. إذا ظهر إصدار أقدم، طبّق تحديثه السابق أولًا. قراءة الملف ليست دليلًا على إصدار الحاوية العاملة.

**2. فك حزمة تصحيح التواريخ:**

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\AeroPlan-Date-Fix-0.14.4.zip" -DestinationPath "$env:USERPROFILE\Downloads\AeroPlan-Docker" -Force -Verbose
```

**3. الانتقال إلى مجلد النظام:**

```powershell
Set-Location "$env:USERPROFILE\Downloads\AeroPlan-Docker"
```

**4. تحديد ملف التشغيل:**

```powershell
$AeroFiles = @('-f', 'compose.yaml')
```

**5. استخدام إعداد الإنتاج الموجود إن وُجد:**

```powershell
if (Test-Path '.\compose.production.yaml') { $AeroFiles = @('-f', 'compose.production.yaml') }
```

**6. الاحتفاظ بإعدادات النسخ والخدمات الموجودة:**

```powershell
foreach ($AeroExtra in @('compose.backup.yaml', 'compose.services.yaml')) { if (Test-Path $AeroExtra) { $AeroFiles += @('-f', $AeroExtra) } }
```

الأسطر 4–6 قد لا تطبع شيئًا؛ هذا طبيعي.

**7. إعادة البناء والتشغيل، ثم انتظار اكتماله:**

```powershell
docker compose -p aeroplan @AeroFiles up -d --build --force-recreate --wait
```

**8. التحقق من إصدار الخادم العامل:**

```powershell
Invoke-RestMethod 'http://localhost:8080/healthz' | Format-List status, version, buildFingerprint
```

المتوقع status = ok وversion = 0.14.4 وبصمة 90e4b12c7eef4351131b91cef3f019e3ae3dc2cfd77265cf613ffe925b232818. قد يبقى وسم الصورة قديمًا لأن ملف Compose محفوظ. حافظ على مشروع aeroplan ووحدة البيانات الحالية؛ لا إعادة init ولا حذف وحدات تخزين.

اضغط Ctrl+F5، وافتح تسجيل الطائرة. جرّب إدخال سنة زائدة والتاريخ 2026-09-31؛ يجب ألا يُعتمدا أو يتحولا تلقائيًا لتاريخ آخر. جرّب 2024-02-29 وتاريخًا عاديًا من سجلاتك، ثم حفظ المسودة وإعادة فتحها. شكل عرض التاريخ يتبع إعداد المتصفح؛ التقويم الأصلي متاح. تحقق من حقول الرصيد UTC ومن بقاء القوائم والساعات والدورات والملاحظات كما هي. لا تدخل قيم الاختبار في سجل تشغيلي معتمد.

نجح البناء وTypeScript وكل مجموعات الانحدار الـ35؛ نجح اختبار التواريخ المحسن في 86 تحققًا و16 طلب API على SQLite مؤقتة. يشمل السنة الطويلة والتواريخ المستحيلة والكبيسة وUTC والحذف ومنع الحفظ غير الصحيح وقفل الحقول وحفظ القيم الأخرى. اختبارات التفاعل بمحاكاة DOM؛ تعذر تشغيل Chromium قبل فتح صفحة بسبب منع socket، ولم تُختبر لوحة المفاتيح المقطعية أو بكسلات المتصفح الفعلي هنا. يبقى تحقق Windows/Docker والمتصفح على الجهاز المستهدف مطلوبًا.
