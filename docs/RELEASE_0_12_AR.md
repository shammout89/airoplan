# AeroPlan 0.12.0 — أولوية قواعد الاستحقاق

أضيف حساب مستقل لـFH وFC والتقويم من الإنجاز الفعلي أو الاستحقاق السابق أو جدول ثابت، وسياسات بمصادر وأدلة مثبتة، وتسامحات لمرة واحدة بمراجعة واعتماد مستقلين، ومعاينة التنفيذ وحفظ الحساب والتصحيح والتقارير وفحص النسخ. تفاصيل الاستخدام: [SCHEDULING_0_12_AR.md](SCHEDULING_0_12_AR.md).

هذا الإصدار ينفذ أولوية الحساب من المراجعة الأخيرة. لا يُعد إعلانًا بإنجاز جميع البنود الأخرى في تلك المراجعة.

## تحديث Windows / Docker

خذ نسخة كاملة من التطبيق والبيانات من «النسخ والاستعادة»، واحفظ المفتاح في مكان مستقل وتحقق من النسخة. لا تحذف مجلد المشروع أو Docker volume.

نزّل `AeroPlan-Docker-Cumulative-Update-0.12.0.zip` إلى Downloads. من مجلد المشروع الحالي، شغّل السطر التالي وحده:

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\AeroPlan-Docker-Cumulative-Update-0.12.0.zip" -DestinationPath . -Force
```

ثم شغّل هذا السطر وحده:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-AeroPlan.ps1 -Build
```

الحزمة تراكمية من النسخة الأصلية 0.9 ومن التحديثات اللاحقة 0.10 و0.11. تحمي `.env` و`compose.yaml` وملفات Compose المولدة وبيانات العمل والأسرار؛ لا تتطلب إنشاء المدير من جديد. بقاء اسم الصورة `aeroplan:0.9-docker` في Compose القديم لا يحدد نسخة التطبيق؛ البناء يستبدل محتوى الصورة، والنسخة الفعلية ظاهرة في الصفحة و`healthz`.

للتثبيت الجديد فقط استخدم `AeroPlan-Docker-0.12.0.zip`، ثم إعدادات Docker والتهيئة الموجودة في دليل الإصدار 0.11. لا تستخدم تهيئة مدير جديد كتحديث لبيانات قائمة.

## تحقق بعد البناء

```powershell
curl.exe -s http://localhost:8080/healthz
```

يجب أن تظهر النسخة `0.12.0`. حدث المتصفح بـCtrl+F5، وافتح تعريف مهمة في البرنامج للتأكد من ظهور «سياسة حساب الاستحقاق». سجل النسخ والجلسات والقبول يبقى خاضعًا للضوابط السابقة. تغير بصمة البناء يستلزم قبول الإصدار الجديد ببيانات الشركة.

إذا ظهر خطأ Docker API 500، فهو يحدث قبل تنفيذ التطبيق؛ شغّل Docker Desktop وانتظر جاهزية Linux Engine. افحص:

```powershell
docker version
```

لا تبدأ تحديث البيانات حتى يظهر قسم Server سليمًا. لا تستخدم Factory Reset ولا `docker compose down -v` لمعالجة عطل Docker؛ كلاهما قد يعرض بياناتك للفقد.

لم تتغير واجهة تسجيل الخروج ولم تعد العبارة التي طلبت حذفها من الصفحة الرئيسية. هذه الترقية لا تعيد حساب أو استبدال المرات المغلقة، ولا تفعّل تسامحًا افتراضيًا للسلاسل القائمة.
