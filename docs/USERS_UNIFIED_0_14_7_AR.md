# تحديث المستخدمين والصلاحيات — AeroPlan 0.14.7

أصبحت إدارة المستخدمين في **الإعدادات ← المستخدمون والصلاحيات**. ينشئ النموذج الاسم والبريد وكلمة المرور وتأكيدها والدور وحالة المستخدم، ويُحفظ الحساب وعضويته معًا. يمكن تعديل الدور والحالة وإصدار رابط إعادة ضبط كلمة المرور من الصفحة نفسها. يتجه رابط «الحسابات المحلية» القديم إلى هذه الصفحة.

تظهر العضويات السابقة التي لا تملك حساب دخول مع زر «استكمال الحساب». يحتفظ هذا المسار بالعضوية نفسها وبريدها ودورها وحالتها المعروضة؛ لا تنشئ مستخدمًا آخر بالبريد نفسه. تبقى روابط التفعيل السابقة صالحة وفق مدتها واستخدامها، ويتوفر اختيار رابط تفعيل ضمن خيارات النموذج نفسه.

إنشاء الحسابات وروابط التفعيل وإعادة ضبط كلمات المرور للمالك فقط. يمكن لمن لديه صلاحية إدارة الفريق تعديل أدوار المستخدمين وحالتهم. حساب المالك محمي من تغيير الدور والتعطيل، ويغير كلمة مروره من «حسابي». تعطيل مستخدم ينهي جلساته؛ إعادة تفعيله تتطلب تسجيل دخول جديد.

## تثبيت التحديث على النظام الحالي

الحزمة `AeroPlan-Users-Update-0.14.7.zip` تحمل المصادر الحالية بصورة تراكمية، وتستثني ملفات Compose والبيئة والبيانات والأسرار وإعدادات التشغيل المولدة. جرى التحقق من التطبيق فوق مصادر 0.14.6. احتفظ بمجلد النظام ووحدة البيانات الحاليين. لا تعد تهيئة المالك أو تحذف بيانات Docker. شغّل Docker Desktop، ثم نفذ الأوامر التالية واحدًا بعد الآخر في **نافذة PowerShell نفسها**.

**١. التحقق من مجلد المصدر:**

```powershell
Get-Content -LiteralPath "$env:USERPROFILE\Downloads\AeroPlan-Docker\release.json"
```

إذا كان مجلد تثبيتك في مسار مختلف، استخدم مساره في الأمرين التاليين. ملف المصدر لا يثبت بمفرده نسخة الحاوية العاملة.

**٢. فك حزمة التحديث فوق المجلد الحالي:**

```powershell
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\AeroPlan-Users-Update-0.14.7.zip" -DestinationPath "$env:USERPROFILE\Downloads\AeroPlan-Docker" -Force
```

**٣. الدخول إلى المجلد:**

```powershell
Set-Location "$env:USERPROFILE\Downloads\AeroPlan-Docker"
```

**٤. اختيار إعداد التشغيل الحالي:**

```powershell
$aeroUserFiles = @('-f', 'compose.yaml')
```

```powershell
if (Test-Path -LiteralPath '.\compose.production.yaml') { $aeroUserFiles = @('-f', 'compose.production.yaml') }
```

```powershell
foreach ($aeroUserExtra in @('compose.backup.yaml', 'compose.services.yaml')) { if (Test-Path -LiteralPath $aeroUserExtra) { $aeroUserFiles += @('-f', $aeroUserExtra) } }
```

قد لا تطبع أوامر اختيار الإعداد شيئًا؛ هذا طبيعي.

**٥. إعادة البناء والتشغيل مع مشروع aeroplan نفسه:**

```powershell
docker compose -p aeroplan @aeroUserFiles up -d --build --force-recreate --wait
```

انتظر اكتمال الأمر وعودة مؤشر PowerShell. لا تعتمد على اسم صورة Docker وحده: تحفظ الحزمة إعداد التشغيل السابق، وقد يبقى وسم الصورة قديمًا رغم تحديث محتواها.

**٦. التحقق من النسخة العاملة:**

```powershell
Invoke-RestMethod 'http://localhost:8080/healthz' | Format-List status, version, buildFingerprint
```

المتوقع:

- `status: ok`
- `version: 0.14.7`
- `buildFingerprint: fbdaf02c20067aaf0fcb4bd4bf0f8b4be678e88db3b982e66294ee20189fc533`

**٧. فحص الشاشة:**

سجل الدخول بحساب المالك الحالي واضغط Ctrl+F5، ثم افتح **الإعدادات ← المستخدمون والصلاحيات**، أو افتح [الصفحة الموحدة](http://localhost:8080/?settings=team).

تحقق من ظهور كلمة المرور وتأكيدها والدور والحالة في نموذج واحد. أنشئ المراجع والمعتمد إن لم يكونا موجودين، أو استخدم «استكمال الحساب» للعضوية القديمة. استخدم كلمتي مرور مختلفتين تختارهما ولا ترسلهما في المحادثة. اختبر تسجيل الدخول بكل حساب واستقلال المراجعة والاعتماد. افتح بيانات الطائرة والمهمة السابقة وتحقق من بقاء العدادات والحدود والمرفقات.

## التحقق المنفذ وحدوده

نجح TypeScript وبناء الإنتاج و٣٨ مجموعة اختبار. تضمنت ١٣٧ تحققًا للمسار الموحد وترقية قاعدة منشأة بكود 0.14.6، و١٨٤ طلب HTTP لخادم الإنتاج، وفحوص الحسابات والمصادقة والتدقيق والنسخ والاستعادة والوظائف السابقة. هذه أعداد متداخلة وليست مجموع حالات فريدة.

شملت محاكاة DOM النموذج الفعلي وأزراره ورسائل الرفض وحفظ المدخلات وعدم تكرار الطلب، مع CSS الإنتاج. تعذر بدء Chromium قبل فتح صفحة، ولا يتوفر Windows/Docker هنا. يبقى فحص المتصفح على جهازك والقبول ببيانات الشركة معلقًا.

جرى تطبيق الحزمة فوق مصادر 0.14.6 وبناؤها وتشغيل اختبارات المستخدمين وHTTP عليها. بقيت ١٢ عينة من إعدادات التشغيل والبيئة والبيانات والأسرار والنسخ دون تغيير.
